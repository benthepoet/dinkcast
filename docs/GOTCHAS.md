# Dreamcast / Dinkcast gotchas

Append **one bullet per class of mistake** (rule + wrong vs right). Not a changelog. Agents must read this before touching FS, CDI, PVR, Docker, or boot. The skill [dreamcast-kos](../.grok/skills/dreamcast-kos/SKILL.md) points here.

## Toolchain and Docker

- **Docker installed ≠ daemon usable.** Need `systemctl start docker` and the user in group `docker` (or `sudo docker`). No socket → no pull/build.
- **Do not bake host `DINK_DATA` into the SH-4 compile.** `-DDINK_DATA_DEFAULT=\"/home/...\"` breaks `kos-cc` (stray `\` / unclosed quote) and is meaningless on the DC. Probe `/pc/dink`, `/cd/*`, `getenv` only.
- **`local.mk` wins over container env.** Host path is invisible inside Docker. Use `make -e cdi` and/or fall back to `/dink` (the mount). Prefer `DINK_DATA ?=` in `local.mk`.
- **`make docker-cdi` must live on `master`.** A target only on a docs branch is `No rule to make target`.
- **Makefile.dc must list header deps.** `kos-cc` incremental builds only rebuild changed `.c`. After `EditorSprite` grew warp fields, `script.o`/`talk.o` stayed on the 60-byte layout. House drew (new `main.o`) but `dinkc preload unique=0` and A found no scripts. `$(OBJS): src/mapscr.h`.
- **Fine-grained `github_pat_` can open PRs and push branches but still 403 `mergePullRequest`.** That is a token permission, not a broken PR. Human merges in the GitHub UI. Never “finish” a PR by rewriting `master`.
- **REIOS ≠ a BIOS.** Flycast without `dc_boot.bin` in `~/.local/share/flycast/` often never runs `1ST_READ.BIN`.
- **Flycast `N[RENDERER]` is not KOS `printf`.** SH-4 serial is SCIF. `make emu` enables SerialConsole and tees combined stdout to the terminal **and** `build/emu.log` (override `EMU_LOG=`). Each run overwrites the file. Settings → Advanced → Serial Console does the same. **When a playtest issue is reported, read that log first** — do not guess from the picture. Grain USE “spam + no sprite” was `seq 431 nframes 0` on a distilled stub, not a missing `sp_seq`. If the log cannot name the miss, **add logging and reproduce**; do not invent a fix.

## Disc and `/cd`

- **Flycast playtest is CHD, not DiscJuggler CDI.** `chdman createcd -i file.cdi` reports 0 tracks. A **GDI** CHD gets GD-ROM metadata (`CHGD`); Flycast then requires 3 tracks and 549300 frames (`Invalid CHD: less than 3 tracks`). Use a two-track **CUE** (4 s dummy audio + data ISO) so the CHD is a MIL-CD. Hardware still burns the `.cdi`. Need `chdman` from `mame-tools`.
- **Every disc file must be a 2048-byte multiple (pad the staged copy, never the source).** KOS fs_iso9660 DMA-streams a whole-file read of the sector-rounded size; a non-multiple size leaves a live GD-ROM stream aborted with data still queued and can wedge the drive (KOS issue #1492, [CD-HANG-ROOTCAUSE.md](CD-HANG-ROOTCAUSE.md)). `make_cdi.sh` stages via `tools/stage_dink.sh`: text (`.c`/`.ini`/`.txt`) padded with **spaces** (the DinkC lexer treats NUL as junk mid-file), everything else with zeroes. Boot binary padded the same way before `-b`.
- **Play-path must not `fopen` every frame; enter-path may reopen after Prev drop.** `dink_blob_get` / `dink_disc_opens` own the cache while a blob lives. Repeat `dir.ff` / tilesheet / `dink.ini` / story on the **play path** must not `fopen` (miss → skip). `map.dat` stays a single `FILE*`. Swap decodes **live** frames from cached packs and frees unused pixels. **14.4b** may `fopen` a Screen pack again after it is two screens old — that is seek + RAM, not hang insurance. **14.5** writes subset `dir.ff` in-place on the **staged** CDI copy (`stage_dink.sh`). Host `DINK_DISTILL=build/distill`; skip-no-save **unlinks** a stale host pack so overlay cannot replace the official innwalls. Never rewrite `DINK_DATA`. Do not overlay `build/distill` onto the stage **before** in-place. Do not `SEEK_END`. Do not `vid_waitvbl` on every fclose. First-open `/cd` hang on non-2048 sizes is KOS #1492; sector-pad retired it in Flycast ([CD-HANG-ROOTCAUSE.md](CD-HANG-ROOTCAUSE.md)). Do not keep packs forever “because `/cd` hangs.”
- **Do not free a blob while ff/hard still point at it.** `dink_blob_get` pointers stay valid until `dink_blob_clear` or `dink_blob_try_drop` of that rel. `ff_load_rel` / `hard_load` borrow them. A 64-slot overflow that `free`s the smallest unpinned file UAFs a live `dir.ff` and reopens it. Grow the table; never evict a live slot to insert another. `ff_cache_release` frees the ff slot first, then drops the blob.
- **Do not calloc the 512 KB tile atlas on swap.** After packs/`hard.dat` the heap cannot `sbrk` 524288. `swap atlas fail keep` leaves the previous floor (old-man house) under the new sprites. CPU atlas is BSS. Decoded `tsNN` sheets may LRU-evict; re-decode from the blob, never `fopen`.
- **`mkdcdisc -d DIR` uses `basename(DIR)` as the folder on the disc.** `-d build/iso` → `/cd/iso/...`. Pass the data tree named `dink` → `/cd/dink`.
- **ISO9660 is 8.3 / often `DINK.DAT`.** `stat("/cd/dink")` can fail; `S_ISDIR` is untrustworthy. `opendir` and open `dink.dat` (case-insensitive). Also try `/cd`, `/cd/DINK`, leftover `/cd/iso`.
- **Empty directory is not a data root.** Only accept a root if `dink.dat` opens.
- **GD-ROM is not ready on the first line of `main`.** Wait for `cdrom_get_status` PAUSED/STANDBY/PLAYING before probing `/cd`.
- **On-screen HUD beats serial.** Use `bfont_draw_str` on `vram_s` so a red screen states `NO DATA ROOT` and lists `/cd`.

## SH-4 stack

- **KOS thread stack is 32–64 KB.** `World` (9 KB) + `MapScreen` (7 KB) + `HardMap.btile_default` (10 KB) + `EdGfx[]` as **locals** smash the stack. Serial then looks like a parse bug (`edraw skip seq=388` — that 388 is a **Y**). Put those in BSS (`static`) or heap. Host `make host` will not catch this.
- **SH-4 int32 must be 4-aligned.** `uint8_t active` + `char script[14]` can make `sizeof(EditorSprite) % 4 != 0` so `sprite[i].seq` is a misaligned load (garbage seq=y). Use int32 `active` and a 16-byte script tail. Snapshot sprites **immediately after `map_load_record`** (BSS copy).
- **`edraw_load_screen` must heap-copy sprites before `memset(g_edg)`.** ELF packs `g_edg` → `g_hard` → `g_atlas` → `g_scr`. Free+memset first, then copy, reads `act=88` (Y). A second BSS `static` table can sit next to `g_edg` and die the same way. `malloc`, copy, then memset; write the snap back at the end.
- **Restore `g_scr.sprite` after edraw before `script_on_main` / talk.** Draw already memcpy’d the snap; attach and `talk_probe` still walked the smashed table (`preload unique=0`, no mom `main`, A does nothing). Keep the snap on the **heap**, not BSS next to `g_edg`.
- **Do not BSS `EdGfx[]` next to `g_scr`.** `edraw.c` and `main.c` can disagree on `sizeof(EdGfx)` if only `main` includes `kos.h`. `memset(g)` then walks into the map table. Serial: `restore … script=s1-h1-m` then `preload unique=0`. Allocate gfx with `edraw_gfx_alloc()`; restore again immediately before attach.

## PVR / video

- **`pvr_txr_load_ex` always twiddles.** Drawing with `PVR_TXRFMT_NONTWIDDLED` yields horizontal stripes of the right colors. Poly = twiddled `PVR_TXRFMT_RGB565`.
- **Brown then stripes = decode OK, upload/format wrong.** Red HUD = never found data (or ELF never ran).
- **640×480 is not a texture size.** Pad to 1024×512; sample with UVs `640/1024`, `480/512`.
- **`pvr_wait_ready` before `pvr_mem_free` of a texture still in the last scene.** Walk/idle frames share a similar `cx`; punch (`ds-h*`, cx ~58) then idle (`ds-i*`, cx ~36) does not. Evict after `scene_finish` but before the next wait and the GPU still samples the old quad — idle pixels appear left of Dink. Wait, then swap.
- **Do not `pvr_wait_ready` when no scene is in flight.** After swap-start wait, edraw CPU work leaves the GPU idle. A second wait before `tiles_upload_pvr` can freeze (`swap atlas ok` then silence; house/outdoor tiles stay). Wait once at swap start (`have_scene`), then upload.
- **`pvr_shutdown` on leave-title leaves the splash in the last PVR frame.** Flycast keeps showing it while we load `map.dat` / editor BMPs (serial already says `leave_title`). Re-`pvr_init` and draw a brown clear immediately, then load. Do not wait until `tiles_upload_pvr`.
- **PT z-buffer is not a FreeDink blit.** FreeDink paints `screen_rank` order into a framebuffer (later opaque pixel wins). Dinkcast PT + GEQUAL with `1.5+i*0.01` put a depth gap between two type-1 sprites at the same y. A third sprite inserting between them (pig on map 407) changed that gap and overlapping punch-through pixels shimmered (south inner-pen fence joint, seq 93 slots 10/22). Draw sorted world sprites at one z so later equal-z wins. Keep that z above tiles (1.0) and below floaters/say/HUD (2.8+). Do not pin seq 93, do not bake type-1 fences, do not special-case map 407.

## Screen changes

- **Flycast load time is not hardware.** Host disk hides seeks. Judge `swap_ms` on a CDI/ODE/burn, not only `make emu`. Serial `swap_ms` on Flycast may be **~0**; that is not the § screen-delay table.
- **14.3 leak deltas are a warm ping-pong, not house vs the 20th unique map.** `file_blob` / Always / `ts_rgb` / `vram_free` must stay within **4 KB** from swap **4** to swap **20** when walking the **same two** screens (439 ↔ 441). `cpu_pixels` may follow the screen. A 20-screen tour that keeps adding unique packs is residency working-set size, not a leak. Screen-vs-Screen `edraw evict` (oldman walk vs duck death filling 96 slots) is occupancy, not 14.3.
- **A loading screen on every edge is a bug.** Keep the current tileset in VRAM. Same-tileset walk: **0.2–0.6 s** on CD. New tileset: **0.5–2 s**. **> 3 s** on a normal neighbor = over-evict or disc order. Title → first map may show “Loading…”.
- **Do not reopen music** unless the screen’s MIDI id changed; that adds another seek.

## DinkC

- **SH-4 is fast enough.** Do not invent a VM or JIT “because 200 MHz.” Graft FreeDink; parse once; table-dispatch; cap ops per frame. Busy loops are a script bug (same as PC).
- **A hitch is not proof scripts are hot.** Profile GD-ROM and texture upload first. Reliability is `wait` / `say_stop` fibers and command coverage, not clock rate.
- **DinkC files are `story/NAME.c`.** `map.dat` has no extension. Over **32 KB** fails that script only (log `dinkc too big`). Never skip a missing file silently (`dinkc miss`). `dink_fopen` already covers `STORY/NAME.C` / 8.3.
- **Screen `script` is at `map.dat` +30240, not 30204.** Sprites start at 8020, 101×220 bytes, then the 21-byte name (`8020+22220`). A FreeDink comment says 30204; those bytes are zeros. Copying 30204 made loc 1 look scriptless (`s1-h1-s` is real). `s1-gate` / `findduck` never ran, so the vision-1 gate guard (`s1-gg`) and Quackers never appeared. `draw_screen_game` still resets `&vision` to 0, runs screen `MAIN`, then places sprites with `*pvision`.
- **DinkC has no `/* */`.** FreeDink is line + `get_word`. Stock `story/` uses `//` only. Lexer skips `//` to EOL. `/*` is `SLASH` then `STAR`, not a block comment. `&s2-map` is one `VAR` (hyphen is ident).
- **Stock DinkC is messy.** Missing `{` after `void name()`, extra `}`, `+=` and `&x / 5`, `choice_start`/`title_start` prose, multiline `"…"`, typos (`wait(200:`, `say_stop('…"`). Parser is permissive; it does not execute.
- **`goto` is `locate_goto` from the start of the file, not a C jump.** Parser `goto ident;` was a no-op (`run_fiber` only advanced `ip`). Scan for `ident:` (case-insensitive) in the whole token stream so `S2-OUT.c` `hit()` can resume `mainloop:` in `main()`. A miss logs `dinkc cannot goto` and leaves `ip` at EOF — do not run the next statement. Colon inside `say("bonus: …")` is a string, not a label.
- **`spawn` is not `external`.** FreeDink `dc_spawn` is `load_script(name, 1000)`, `locate(MAIN)`, `run_script`. Parent is `DCPS_GOTO_NEXTLINE` (no `WAIT_EXT`). Return is the new script slot; miss is 0. Sprite 1000 keep survives screen `kill_all` (bombs `ITEM-BOM.c` `spawn("dam-bom")` then `kill_cur_item` on the same tick). Do not attach the child to the caller’s sprite.
- **`wait(ms)` is a fiber yield**, not a busy loop. 60 Hz tick is 16 ms. `say_stop` yields until A. Do not attach/run house `main()` until 11.5/11.6 — it `freeze`s and `say_stop`s.
- **DinkC 1.08 looks up locals before globals.** Unknown `&name` is 0. Engine names `&current_sprite` / `&current_script` / `&return` / `&arg1`–`9` are not `play.var` slots. Only register `MAIN.c` `make_global_int` names — do not invent extras.
- **A while `choice_start` picks the first visible line** until Bite 13 draws the menu. `&result` is FreeDink `line_return` (hidden lines still increment). 0 visible lines do not yield. Serial `say` is the 11.5 box. Do not `freeze++` in the engine on talk — `freeze(1)` in the script is the nest.
- **`playmidi` is an implemented no-op** until 12. `fade_*` / `fill_screen` stay instant (no fade clock). `draw_status` / `update_status` are **16.3**.
- **`load_screen` is not an edge warp.** FreeDink `dc_load_screen` is `game_load_screen(loc[&player_map])`. Args are ignored (`S1-HOLE.c` writes `load_screen(131)` after `&player_map = 131`). It loads the record, thaws Dink, clears `screenlock`, restamps tile hardness. It does **not** `kill_all` or place sprites. Edge/warp already call load then draw atomically; DinkC needs the two steps.
- **`draw_screen` is `draw_screen_game`.** Vision 0, `kill_all` except sprite ≥ 1000, tiles, screen MAIN, live attach. `S1-LTR.c` `script_attach(1000)` before load/draw so the fiber survives `kill_all` and continues (`fade_up` / `unfreeze` / `kill_this_task`). Hole scripts are not 1000: nothing after `draw_screen()` runs (yield 3 here; FreeDink `DCPS_YIELD` then the script is already dead). Do not map that yield to `WAIT_SAY`.
- **`screenlock` is `dc_screenlock` + `get_hard` clamp, not a fade.** 1.08: `0` or `1` sets; any other arg (or none) returns the current lock. `did_player_cross_screen` will not wrap while locked (clamp like an empty neighbor). `get_hard` clamps OOB samples onto 0..599 / 0..399 so diag-off-the-border does not skip hardness. `game_load_screen` clears it. Warps still run. No lock-bar gfx (`drawscreenlock`) until a later HUD bite.
- **`sp_follow` is `process_follow`, not a pathfinder.** FreeDink: inactive target clears `follow`; dist **< 40** does not walk; else `get_distance_and_dir` + `changedir` + `automove`. We graft **nosmooth** (`get_distance_and_dir_nosmooth`; default dir 6). Equal X or Y leaves that axis at 5000, so an aligned sprite still walks. Duck / people / no_brain / dragon / pill call it after freeze. Brains 5/7 (`one_time_brain` / `one_time_brain_for_real`) call it too. **`pig_brain` does not** (`brain_pig.cpp`). `S1-DUCK.c` is `sp_follow(&current_sprite, 1)`.
- **`sp_target` lives on `BrainSpr`, not a side array.** Do not keep `g_target[]`. `process_target` is the same walk as follow but the stop radius is `spr.distance` (pill defaults 5). Pill ATTACK uses nosmooth dir + `base_attack+dir` and `locate("ATTACK")` — a miss sets `move_wait`. Dragon (`brain_lateral.cpp`) only `locate("ATTACK")` when `attack_wait` elapsed; it does **not** use the pill walk-in. Pig has neither. `sp_attack_wait` stores **`arg + thisTickCount`** (absolute deadline).
- **`DINKC_DUMP_FNS=1`** prints `dinkc dump implemented=` at bind/atexit and after screen attach. Missing names are unique first-seen calls not in `k_fn[]`. Add the name to the table (even as a stub) instead of a second if-chain.
- **Official freeware data has no dialog font BMP.** Original Dink used GDI (Arial-like); FreeDink uses LiberationSans TTF. Do not ship TTF on the DC. 13.1 is an embedded public-domain IBM VGA 8×8 atlas (16 KB ARGB1555), not LiberationSans. Say box is 13.2.
- **`say` is sprite-anchored, not a HUD bar.** FreeDink `say_text` then `text_brain`: each frame `x = owner.x-75`, `y = owner.y-100` (default defense) unless `text_owner==1000`. Snapshot-once leaves `FINDDUCK` “There's that duck!!” behind Dink. Wrap 150, `` `X `` color prefix. `text_draw` calls `print_text_wrap` with **hcenter=1** in that 150 box (each line centered over the sprite, not left-aligned at x-75). A **or** B advances `say_stop`. Do not punch on B while a line is up.
- **`say()` has a TTL; it is not a permanent HUD.** FreeDink `add_text_sprite` sets `kill_ttl = max(strlen(text)*77, 2700)` ms (`TEXT_TIMER` / `TEXT_MIN`). `live_sprite_set_kill_start` then `live_sprite_is_expired` removes the brain-8 sprite. Ethel `s1-h2-o` MAIN and X-with-no-magic (`I'm no wizard!`) are `say`, not `say_stop` — they never yield, so A/B cannot be the only clear. `say_stop` uses the same TTL; expire runs `say_stop_callback`. Do not leave the line up until the next `saybox_set`.
- **Say color is `font_colors[1..15]`, not “NPC vs Dink”.** FreeDink `text_draw` strips leading `` `X `` and indexes `gfx_fonts_init_colors`. Drawing only 13/4/15 and falling through to yellow 14 makes Chealse `` `5 `` look like Dink. Graft the full table (5 = magenta 222,173,255). 1.08 also maps `` `@ ``→12 and `` `! ``→11.
- **`freeze` is not a nest.** FreeDink sets `spr[1].freeze` to the script id (any non-zero). `unfreeze` clears it. If the fiber dies before `unfreeze`, Dink stays locked — thaw when `dinkc_vm_live()==0`.
- **Choice menu is seq 30 + centered lines, not a `>` list.** FreeDink `game_choice_renderer` blits `main-` frames 2–4 at (48,44)/(217,86)/(397,45), `print_text_wrap` hcenter in 184–463, and arrows seq 456/457. `game_choice_logic` vertically centers when one page fits (`((335-sy_hold)/2)-20`). Selected is white, others yellow `{255,255,2}`. A `>` gutter at x=80 is not Dink. Load overlay once at leave-title (keep off the 96-slot screen table). Arrow BMPs are loose files, not `dir.ff`. D-pad (and left/right) + A; `&result` is the official line number.
- **DinkC extra `}` does not end the proc.** FreeDink `process_line` clamps `level` back to ≥1; `s1-h2-o` `talk()` has a stray `}` before the `unfreeze` after agreeing to find Quackers. Killing the fiber on `depth <= 0` left Dink frozen (idle still plays). Continue; stop on `void` / `return` / EOF.
- **HIT/TALK `locate` on the MAIN keep fiber.** FreeDink does not `start_proc` a new instance. `s1-gg` declares `int &mrandom` in `main()`; assign to a missing local is a no-op, so punch `hit()` is silent. Sprite keep dies on screen swap; item ARM (sprite 1000) does not. `kill_returning_stuff` drops wait callbacks only.
- **A with no talk target still says.** FreeDink `human_brain` random 6 lines (`Not much happening here.` is one). Empty `script_on_talk(0)` is silence. Same for **X** with no armed magic (`I'm no wizard!` is one). Official data has no `dnotalk`/`dnomagic`. Not freeze/`say_stop`. Y inventory is **16.2**. Push, escape menu, and map/`button6` stay later bites.
- **House exit is a warp, not an edge.** Hardness `100+editor` + `is_warp` (`special_block`). Edge is `did_player_cross_screen` (playl=20, x=619, y=0/399, map ±1 / ±32). Clamp if `loc[neighbor]==0`. Instant swap (no fade).
- **Enter-house `parm_seq` is the door animation.** Map 439 sprite 13 is type-1 seq/`parm_seq` 61 (`odor1-`). Instant warp skips it. FreeDink `special_block` plays that seq on the live sprite and `process_warp_man` waits until `seq==0`. Exit door is type-2 `parm_seq` 0 (still instant). Load every `parm_seq` frame at screen enter; play-path must not `fopen`.
- **Do not `tiles_evict` before the new atlas is uploaded.** Swap that frees tile PVR first leaves the last house frame (Dink in the doorway) on screen. If stamp/atlas/upload then stalls, it never draws map 439. Free CPU atlas only; replace PVR in `tiles_upload_pvr`. Serial: `warp … enter map 439` then `edraw unique 16` and silence.
- **Do not brown-clear every screen swap.** Plan: a loading screen on every edge is a bug. `tiles_draw_clear_pvr` after the house door left a stuck brown field while `hard.dat` (~2 MiB) reloaded. Keep the previous tiles on screen until the new atlas uploads.
- **Do not slurp all of `hard.dat` (~2 MiB) on leave-title.** `dink_blob_get` of the whole file hangs after `atlas cells 96`. Keep one `FILE*`; `SEEK_SET` the default-id table (~21 KB) and each used rec (~2.6 KB). Do not `SEEK_END`. Do not `thd_pass` mid-`fread`. One mutex around each `/cd` fopen/pread.
- **`dir.ff` packs can be ~0.7–1.6 MB.** `edraw load seq=63` is `graphics/struct/home/dir.ff` (~692 KB). One `fread` of the whole pack from `/cd` stalls (title, house exit, or north). Do not `ini_count_ff_frames` then `sprite_load` (two full reads). Chunked read; keep one buffer (no parse memcpy).
- **Drop two-screens-old packs before fopen Screen.** House → 439 → 407 left innwalls/mom/details in `file_blob` until `swap_end` *after* load. First pig-pen visit `mem refuse` seq 41 (`graphics/animals/pig/dir.ff` 96 KB) then dropped those house packs. Touch this Screen’s pack dirs (so a backtrack is not dropped), then `ff_cache_drop_unpinned`, then `load_one`. Do not seq-id-pin pigs.
- **Screen fopen drops age-0 Prev `dir.ff` when over the file_blob cap.** Age-1 drop is not enough: village gate (map 408 vis 1) skipped seq **293** (`graphics/people/knight/silver/dir.ff` ~506 KB) at `have=4415488 cap=4718592` while Chealse (`s1-lg` seq 331, girl pack already cached) drew. Do not drop tilesheets or `hard.dat`. `create_sprite` packs are not editor rows — `swap_begin` demotes them to Prev; mark those seqs Screen before the yield so the girl pack is not the victim. Do not seq-id-pin 293.
- **Drop Prev before the slurp malloc, not after.** `dink_fread_all` used to grow 32 KiB → 1 MiB for a 594 KB pack. Map 409 (Ethel outdoor) skipped seq **63** (`graphics/struct/home/dir.ff`) with KOS `Out of memory` `sbrk` 1048576 while 408’s girl/knight/landmark were still Prev. The cap check ran after that realloc, so it never dropped them. `fstat` the size (not `SEEK_END`), `residency_make_room`, then read into that many bytes. South to 441 and back north “fixed” it because 441 had already dropped those Prev packs. Do not pin seq 63.
- **Reopen hang was never confirmed.** `ff load` with no `ok` (including a third `trees/dir.ff` west after east) matched KOS #1492 on unpadded files, not a reproduced post-pad “reopen is unsafe” bug. Sector-pad retired that class in Flycast. **14.4b** Always (named player/UI prefixes) plus **this Screen** and **one Prev** is a RAM working set; older packs drop. Play-path `edraw_ensure_frame` still must not `fopen`; a miss skips unless **14.5** distilled that frame into the staged subset `dir.ff`. Enter-path `edraw_load_screen` may open Screen packs Prev already dropped — seek + `file_blob`, not a hang veto. 14.4a recorded `14.5: needed` for over-cap. Sticky seq **164**: decode all frames, drop the pack, keep pixels. Do not size-pin ≥80 KB. Do not rewrite official `DINK_DATA` packs.
- **Distill is the stock campaign, not the 14.4a village walk.** Union used frames from **every nonempty `map.dat` screen**, including `sp_script` / `script("…")` / `add_item("…")` / `add_magic("…")` callees. Skip-no-save unlinks a stale host `build/distill` pack. Campaign union does **not** put Always+Screen+Prev under 4.5 MB; `mem refuse` is not distill. Per-frame TOC/offset load is **14.6** (after 16 / full-campaign go). **Pixel class eviction is 14.4c** (not 14.6, not distill). A map-only union leaves `item-pig` unread: `graphics/effects/seed/dir.ff` distilled to `SEED6-04` only, USE seq 430/431 skipped every tick.
- **Play-path `edraw_ensure_frame` must not `fopen`.** After mom `unfreeze`, people_brain switches to walk seqs 351/353/357/359 in the same `graphics/people/mom/dir.ff` (~528 KB). Open that pack with **frame 1 of each walk dir** at screen load; remaining frames decode from `ff_cached`. Do not dump every people-walk frame into the 96-slot `EdGfx` table first. A miss may decode from a pack already in `ff_cached`; if the pack was never opened this session, skip the frame. Default corpse seq **164** is the same class: load its frames at `edraw_load_screen` when a type-1 on this vision has `base_die` or a duck/pig/pill/dragon brain — **not** people hitpoints (start-house mom is hp 10).
